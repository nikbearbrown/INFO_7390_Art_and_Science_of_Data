## 1. Defining Statistical Learning

### What Is Statistical Learning?

Statistical learning is a framework for **understanding data by modeling relationships between variables**. While modern machine learning often prioritizes predictive accuracy, statistical learning emphasizes:

* **Inference**: understanding how predictors influence outcomes
* **Uncertainty**: quantifying confidence in those relationships
* **Interpretability**: preferring models that can be reasoned about

At its core, statistical learning assumes that observed data are generated by an underlying process:

[
Y = f(X) + \epsilon
]

Where:

* (Y) is the response variable
* (X) represents predictors
* (f) is an unknown function we aim to estimate
* (\epsilon) is irreducible error (noise, randomness, unobserved factors)

The goal is not to eliminate error, but to **understand structure despite it**.

## 2. Models of Data vs. Models of Systems

A central distinction in modeling is whether we are analyzing **observed relationships** or **underlying mechanisms**.

---

### Models of Data

**Concept:**
Models of data treat observations as **static snapshots**. They describe correlations present in a dataset without modeling how the system itself evolves.

Key characteristics:

* Often assume independence between observations
* Focus on prediction or association
* Do not encode how the world works

**Example: Prostate Cancer Dataset**
Using patient PSA measurements and tumor characteristics to predict outcomes.

The model:

* Learns mathematical patterns
* Does not understand cancer biology
* May fail if conditions change

This is powerful — but limited.

---

### Models of Systems

**Concept:**
Models of systems represent **rules governing change over time**.

They model:

* States
* Transitions
* Dynamics
* Constraints

These models are grounded in domain knowledge.

**Example: Flight Simulator**
A simulator encodes physics, not historical data alone. It can predict behavior in novel situations because it models **mechanisms**, not just correlations.

---

### Summary Comparison

| Models of Data    | Models of Systems   |
| ----------------- | ------------------- |
| Correlation-based | Mechanism-based     |
| Static            | Dynamic             |
| Data-driven       | Rule-driven         |
| Often brittle     | Often generalizable |

## 3. Learning Paradigms

Statistical learning methods can be categorized by **how information is provided**.

---

### Supervised Learning

The model learns from labeled examples ((X, Y)).

#### Regression

* Continuous outputs
* Examples: salary prediction, temperature forecasting

#### Classification

* Categorical outputs
* Examples: spam detection, disease diagnosis

The key idea: **learning from a teacher**.

---

### Unsupervised Learning

No labeled response variable is provided.

The model must discover structure on its own.

Common goals:

* Clustering
* Dimensionality reduction
* Pattern discovery

**Example:**
Clustering gene expression profiles to discover disease subtypes without predefined labels.

This is exploratory, not predictive.

## 4. Discriminative vs. Generative Models

> **Insert Image Here:**
> *Discriminative vs. Generative Models (Animals Diagram)*

This distinction concerns **what probability distribution a model learns**.

---

### Discriminative Models — (P(Y \mid X))

Discriminative models learn **decision boundaries** between classes.

They ask:

> *Given these features (X), what is the probability the observation belongs to class (Y)?*

They focus on:

* Classification accuracy
* Separating classes
* Mapping inputs directly to labels

**Lecture Example:**
Handwritten digit recognition.
Given pixel values, decide whether the digit is a **“3” or an “8.”**

The model does not learn what a “3” *is* — only how to distinguish it from other digits.

Common examples:

* Logistic regression
* Support vector machines
* Neural classifiers

---

### Generative Models — (P(X \mid Y))

Generative models learn the **distribution of data within each class**.

They ask:

> *What do the features (X) that define class (Y) look like?*

Because they model how data are generated, they can:

* Create new examples
* Handle missing data
* Simulate realistic observations

**Lecture Example:**
A model that learns what makes a **lion** a lion so well that it can generate an entirely new lion image that never existed — the conceptual basis of generative AI.

Common examples:

* Naive Bayes
* Gaussian mixture models
* VAEs, diffusion models, large generative models

## 5. Reinforcement Learning: Agent–Environment Interaction

> **Insert Image Here:**
> *Reinforcement Learning Agent–Environment Diagram*

Reinforcement Learning (RL) differs fundamentally from supervised and unsupervised learning.

Instead of learning from a fixed dataset, an agent learns by **interacting with an environment over time**.

---

### Mapping Reinforcement Learning to Pac-Man

We will ground each element of the RL framework in **Pac-Man**.

---

#### Agent

**Pac-Man**

The agent is the decision-maker. It chooses actions based on the current state.

---

#### Environment

**The game world**

Includes:

* Maze layout
* Pellets and power pellets
* Ghosts and their behavior
* Game rules and physics

The agent does not control the environment — it only influences it.

---

#### State ((S_t))

**The current game situation**

May include:

* Pac-Man’s position
* Ghost locations and directions
* Remaining pellets
* Ghost vulnerability state

The state summarizes everything needed to decide the next action.

---

#### Action ((A_t))

**Pac-Man’s movement choice**

Actions include:

* Up
* Down
* Left
* Right

---

#### Reward ((R_t))

**Immediate feedback**

Examples:

* +1 for a pellet
* +10 for a power pellet
* +200 for eating a ghost
* −500 for being caught

Rewards are local; success is long-term.

---

#### State Transition ((S_t \rightarrow S_{t+1}))

After an action:

* The environment updates
* Ghosts move
* A new state emerges

The agent learns from these transitions over time.

---

### Why RL Is Different

* No labeled “correct” actions
* Feedback is delayed
* Actions affect future data

The agent learns a **policy**:

> A strategy for choosing actions to maximize cumulative reward.

---

## 6. Forecasting and Time Series

Many statistical models assume **independent observations**.

Time series violate this assumption.

Examples:

* Stock prices
* Weather
* Sensor data

Here:

* Order matters
* Yesterday influences today
* Shuffling destroys meaning

Specialized models are required.

---

## 7. Causal Modeling and the Confounding Trap

Statistical learning identifies **correlation**, not causation.

---

### The Confounding Example

Observation:

* Ice cream sales increase
* Skin cancer rates increase

Naive conclusion:

* Ice cream causes skin cancer

Hidden confounder:

* Sun exposure

Hot weather causes:

* More ice cream consumption
* More UV damage

---

### Causal Goal

Causal modeling asks:

> *What happens if we intervene?*

This requires:

* Domain knowledge
* Assumptions
* Careful study design

Prediction alone is insufficient.

---

## 8. The First Rule: Visualize First

Before fitting any model:

**Always look at your data.**

Visualization helps:

* Detect outliers
* Identify nonlinear relationships
* Catch data errors

**Example:**
A scatter plot revealed a reported prostate weight of 449g — a typo confirmed by a urologist.

No algorithm would have caught this automatically.

Visualization is not optional.
It is the first diagnostic step.
